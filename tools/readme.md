# Tools Module

The tools module contains helper functions used by the AI Customer Support System.

## Purpose

These tools allow AI agents to perform specific tasks and access the functions they need to assist customers.

## Main Functions

- **Order Tools:** Help retrieve order status and delivery information.
- **Refund Tools:** Assist with refund and return-related requests.
- **Technical Support Tools:** Help with common technical issues.
- **Product Tools:** Provide product-related information.
- **Business Tools:** Support business-related queries.

## Technologies

- Python
- Google Gemini API
- AI Agent Integration

## Usage

The specialized agents use these tools to process customer requests and provide appropriate responses.
